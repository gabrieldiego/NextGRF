# Credits and sources

- NextGRF vehicle definitions, wagon generation rules, editable meshes, renderers, compiler generators,
  tests and PDF tools: created for this project; GNU GPL version 2.
- Fictional manufacturers and default vehicle balance references: OpenTTD / the
  Transport Tycoon vehicle roster. Default properties are read from this local
  checkout's `src/table/engines.h`; this project does not modify them.
- Default catalog sprites: OpenGFX2 Classic 0.8.1, by OpenGFX2 and OpenGFX
  contributors, GPL version 2 or later. Full upstream credits and license are in
  the pinned reference archive's `readme.md` and `license.txt`.
  https://github.com/OpenTTD/OpenGFX2
- The default sprite extractor follows the documented GRF format and the
  behavior in OpenTTD's `src/spriteloader/grf.cpp`, GPL version 2.
- The renderer uses NML's DOS palette at build time, GPL version 2 or later.
  Compiler: https://github.com/OpenTTD/nml
- `assets/concepts/aircraft-study.png` was generated with the built-in image
  generation tool as a styling study. It is not included in the game package.
  The archived prompt summary and its limitations are recorded in `PROMPT.txt` beside it.

No original Transport Tycoon bitmap files or proprietary vehicle images are
included. OpenGFX2 is a separate base set; NextGRF is an independently built
vehicle extension and is not an official OpenGFX2 release.
